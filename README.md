# CliScreenshot

CliScreenshot 是 Windows 10/11 x64 的托盘截图工具。截图支持矩形、箭头、画笔和文字标注。保存后可把文件路径粘贴到本机终端。

## 截图

1. 双击 `CliScreenshot.exe`，然后按 `Alt+Shift+S`。将鼠标移到窗口上可预览窗口范围，单击选中窗口，也可以拖动鼠标自由框选。
2. 选定截图区域后默认画矩形，也可从工具栏选择箭头、画笔或文字。文字框从一个汉字宽度开始，到选区右边缘自动换行，按 `Enter` 确认文字。
3. 每笔完成后自动切换到选择模式。点击任意标注可选中，拖动本体可移动，拖动边角控制点可分别调整宽高。箭头的两个控制点可调整方向和长度。可以用工具栏的色板改色，用橡皮擦或 `Delete` 删除，用 `Ctrl+Z` 撤销，或用 `Ctrl+Y` 重做。工具栏可从左端拖动。
4. 选区内外均可双击完成截图，也可按 `Enter` 或点击工具栏的 `✓`，完成后会复制截图路径。点击 `×` 可放弃截图。输入文字时，按 `Esc` 取消当前文字输入。
5. 回到终端，用平时的粘贴快捷键粘贴路径。在 Windows Terminal 里可按 `Ctrl+Shift+V`。图片的引用语法由 CLI 决定，例如 Codex 的 `-i "路径"`，或 Pi 的 `"@路径"`。命令行参数中的路径有空格时加引号。

## 设置与清理

右键点击托盘中的 CliScreenshot 图标，选择「设置」修改全局截图快捷键和自动删除时间。首次运行使用 `Alt+Shift+S`。已经保存过的快捷键可在设置中更换。

截图保存在 `%LOCALAPPDATA%\CliScreenshot\captures`，也可以通过托盘里的「打开截图目录」查看。默认在保存后 **10 分钟**自动删除。修改保留时间时，已有截图按各自的保存时间重新计算。工具退出期间到期的文件会在下次启动时清理。已经粘贴的路径会在文件删除后失效。

## 构建

需要 Rust 1.86 或更高版本、`x86_64-pc-windows-msvc` 工具链、MSVC 构建工具与 Windows SDK。

```powershell
cargo test --locked
cargo build --release --locked
```

可执行文件位于 `target\release\CliScreenshot.exe`。
